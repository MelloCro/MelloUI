**2.1.36: A map your size** 🗺️

**Size it, move it, no Edit Layout.** The map now has a small dotted grip in its bottom-right corner: drag it to make the map bigger or smaller. The quest log beside it keeps its full size, so it stays easy to read even on an ultrawide screen. Right-click the grip to go back to the standard size and place. And you can drag the map's title bar to move the window anywhere.

**Tip:** if you shrank the map in Edit Layout before, that shrank the quest log too. Ctrl+right-click the map's plate in Edit Layout once to reset it, then size the map with the new grip.

**Housekeeping.** Coming from 2.1.32 or newer, a /reload is enough; from 2.1.31 or older, restart the game fully. Voice pack: still the one from 0.18.3.
