**2.1.90: fixes** 🔧

**Target buffs and debuffs.** Hovering a buff or debuff under the target frame shows that aura's own tooltip again. On a target with both, another aura's tooltip could show, and the target frame lit up as if you were pointing at it. Thanks sh4dd0w!

**Controller.** MelloUI's copy window (/mellobug, /mellolog) no longer takes the keyboard from the game's chat line. With the Gamepad UI on, click the text to select it. /mellobug also says more now about where the game's pad buttons go wrong: if you play with a controller and the game blocks an action, that report helps a lot.

**Housekeeping.** A /reload is enough after updating. Voice pack: still the one from 0.18.3.
