**2.1.75: chat your way, and a damage meter you can move** 💬

Thank you 轻风细雨 for a whole list of fixes and chat ideas!

**One line per message.** The Minimal Chat View can now show each message on one line, in the order the game's own chat uses: the time, the channel, the name and the words. Turn on One Line Per Message (Chat > Messages > Text). Off, the name stays over the message as before.

**Tab switches channel.** Turn on Tab Switches Channel (Chat > Messages > Behaviour) and Tab moves your typing line to the next chat you can speak in: Say, Party, Raid, Instance, Guild, then your channels. Shift-Tab goes back, and your words stay where they are. Name suggestions, whisper targets and slash commands keep their own Tab.

**Short channel tags in every language.** Short Channel Tags now shorten channel names on game clients in every language, in both chat views: a channel without a tag of its own shows its first character (综 for 综合, A for Allgemein). Before, a Chinese client saw half a character in the game's windows and the whole name in the Minimal view. Forever's own channels, like Newcomer Chat and Trade (Local), have tags too.

**Fixes.**
- With MelloUI's Damage Meter turned off, the game's own meter sat in a corner with no way to move it. It now has its plate in Edit Layout, so you can drag it anywhere.
- Friendly nameplates that show only the name no longer get a plate border round the name on mouseover.
- Channels that other addons join to talk to each other in the background no longer show up as tabs in the Minimal chat.

**Housekeeping.** A /reload is enough after updating. Voice pack: still the one from 0.18.3.
