# **MelloUI Oldschool – MelloUI's Painted Look**

_The painted stone-and-parchment reskin MelloUI started with, now an addon of its own. It runs beside MelloUI: install both, and everything painted is back, your settings included._

## What it does

*   **The game's windows, painted:** the character window, bags and bank, merchants, mail, trainers, the spellbook, the quest dialogs and many more on painted stone, each with its painted frame and portrait ring.
*   **Painted frames and bars:** the unit frames' art, the action bars' art and backdrops, the cast bars, the nameplate kit, a border style for every kind of window, and the round painted minimap with its zone plate.
*   **Eight palettes:** Ember, Obsidian, Royal Azure and Fel Ember, each with a Vibrant version and its own painted kit.
*   **Parchment:** tooltips, the quest and gossip dialogs and the character window on parchment, the text in dark ink.
*   **Its own setup:** with Oldschool on, the installer's Full experience brings the painted look with its own layout, and Reskin only paints the UI you already have.

## Install

*   **Needs MelloUI.** Install both; the CurseForge app brings MelloUI along.
*   **Keep both on the same version.** An Oldschool from another MelloUI version stays off and tells you so.
*   Its settings are on MelloUI's **Oldschool** page (`/mello`). Don't want it for a while? Untick it in the game's addon list.
*   New files with each update: restart the game once, `/reload` isn't enough.
