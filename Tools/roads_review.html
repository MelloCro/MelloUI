Red lines are the traced roads; click one to drop it (grey, dashed), click again to keep it. "Draw a road" then click along a missing road, double-click to finish (blue). Save writes review.json: put it in Tools/roads/ and run python Tools/trace_roads.py bake. Load brings an earlier review back. The page reads Tools/roads/segments.json and the zone images from Tools/cache/zonemaps/<build>/; browsers refuse that from a plain file, so serve the Tools folder: python -m http.server 8765 in Tools, then open http://localhost:8765/roads_review.html.
