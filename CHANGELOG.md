# Changelog

## 0.13.7

- Lighter textures: the painted kit, the window art and the icons now ship compressed (BLP), small pieces packed into a few atlas sheets, and art drawn smaller than its size scaled to what the screen shows. The textures take 28 MB instead of 96 MB, and a look loads 113 files instead of 330 during the loading screen (12.6 MB instead of 45.8 MB), so first opens and loading screens are quicker. Every compressed piece was checked against its original; pieces where compression would show stay uncompressed.
- New logo: the MelloUI emblem in the AddOn list and the configurator, the whole logo on the configurator's home page.
- No more stalls when opening things: the configurator builds a page's visible part at once and the rest over the following frames (the first click on UI Modifications no longer freezes the game for a moment), tab clicks and hovering rows make no garbage, and Dynamic UI Modification starts over a few frames. The friends window and the group finder dress what you see first and the rest right after; the quest log's updates cost a third of what they did; the bags and the spell book do less on their first open. The Services bar no longer checks every service at once, and custom sounds make no garbage per sound (/sfx shows how long the game takes to play each file the first time).
- Route's road network and its quest objective places now live in a second folder, MelloUI_Companion, which loads only when a route is needed, and the road graph is built over a few frames the first time you route somewhere instead of at login: several MB less memory whenever you are not routing. The download holds both folders: copy MelloUI and MelloUI_Companion into AddOns and restart the game once. /route status says whether the road data is loaded.
- Less memory for the painted kit: its textures, the game art it fades and the text inked on parchment share their handlers instead of each carrying its own.
- Hidden parts stay quiet: the player's resting glow and the pet's attack glow no longer keep pulsing while Hide Status Glow hides them, the micro menu's skin rests while the menu is hidden, the quest tracker no longer re-applies its fonts on every update, the target-of-target portrait is only refitted when it changes, and a hidden tooltip health bar is no longer recoloured.
- Text on parchment no longer flickers white: a nameplate, a unit frame or an action bar passing behind a window no longer puts its text back in the game's colours for a moment (only the window's own plates count), switching the character window's tabs shows the Reputation, Skills and PvP text in ink at once, and new rows in those panes are inked as they appear. Tooltips on parchment are inked the moment the game fills them, including the Game Menu button's latency lines and the unit frames' names, which the game refreshes while you hover.
- Visiting a flight master no longer stalls the game for a moment: Route stops re-reading every zone's flight points once it knows your own.
- Profiles keep what is yours: loading a profile (or a module's Defaults) no longer erases your characters' known flight points, the game settings MelloUI borrowed (whisper mode, world text scale, chat class colours, surname display) or steps done once, and shared profile strings no longer carry any of it, your character IDs included. Strings shared before are cleaned when imported.
- Record Dialog Lines (Voice Over) is off by default: it is only for making new voice lines. Turn it back on under Voice Over if you use it.
- Less work while nothing happens: the Stats readout, custom sounds' hover look and the dungeon entrance check no longer run every frame or every few seconds when there is nothing to do, and whispers from a big guild no longer look through the whole guild list each time.
- Help lists every command players use, What's new covers this whole release, and no text in the game points at developer tools any more.
- Button rims without the constant checking: the painted kit no longer looks at every button ten times a second. A rim changes the moment its button is clicked, a key is pressed, the bars change state or a fight ends; a hover or press the game never reported still clears within a second, and a right-click that ends repair mode takes the gold off the repair button at once.
- Reduce Motion works with UI Modifications off too: the route marker, the tracking notice, the Quest List's flash, the Voice Over subtitles, the chat's scrolling and the configurator's hover all follow it. The tracking notice no longer runs every frame while it waits to fade.
- Less work when windows change: the bank, mail, merchant and eleven other windows refresh their look in one shared pass a frame and make no garbage; collapsing a Quest Tracker section no longer lays every background again; scaling the tracker, tooltips, the Voice Over overlay, the configurator or a window you scale with the wheel lays only that window's backgrounds again; and the character window and spell book, built ahead after login, wait until the end of a fight's catch-up work.
- MelloUI's Edit Mode layout for wide (21:9) screens is the new Immersive arrangement: fewer bars on screen, the middle of the screen left free for what pops up (loot, loss of control, boss bars), the damage meter and raid frames in the top-left corner and the bag bar on the micro menu. Applying MelloUI's layout works again on the patched game client, which changed the format of shared layouts.
- Values the game protects from addons are checked the same safe way everywhere: class icons, the error filter, names in chat and on frames, inked tooltips and several windows' portrait art no longer run into an error when the game hides a class, a name or a message.
- World Text Scale (Tweaks) keeps your own game setting: it is saved once and given back when you turn the option or the module off (after a reload it used to be overwritten).
- A test switch for window frames drawn from one texture instead of eight (fewer textures per window, the same look): /mellokit slices on|off, and /mellokit slicetest shows both side by side. Off by default.
- Smoother play, measured with /melloperf: the parchment ink no longer re-reads whole windows every second (a 40-50 ms hitch each second while the quest tracker or a parchment window was shown); it inks new and changed text as it appears, in slices of about a millisecond, and makes almost no garbage. Opening a parchment window no longer stalls. The Services bar, custom sounds, cooldown numbers, tooltips, the Quest List and the bags stop working while nothing changes, instead of every frame.
- Rarely used windows are dressed the first time you open them instead of at login (shops, mail, bank, trainers, books, charters, inspect, the dressing room, barber, socketing, the stable, PvP, calendar, clock, channels, help, macros, Edit Mode, the AddOn list, Options, group finder, collections, legacy, guild, professions, social): less memory and a faster login, with no flash of the plain window on the first open. The character window is built ahead in small steps after login, so its first open is quick.
- Less memory: the road network is no longer kept twice once Route has read it, a route search makes a tenth of the garbage it did and stops searching again for a destination it cannot reach until something changes, quest objectives are kept packed until Route needs one, and the Quest List and Voice Over keep their quest data leaner. /route reset keeps the traced roads and forgets only what you walked.
- /melloperf load now also shows the memory each file and each module makes while loading and switching on.
- Performance check: /melloperf (or /mello perf) shows what MelloUI costs, from the game's own addon profiler (MelloUI's time per frame, its share of the frame, its slowest frames) and from MelloUI's own measure. /melloperf record [seconds] measures every file and every handler while you play (time per frame, calls, the slowest single calls, the memory each one makes and what runs every frame) and opens a report to copy; /melloperf load lists how long each file took to load and each module to switch on. Measuring only runs while you record.
- More windows in the kit, each with its own switch under UI Modifications, Windows: the Macros window (Macros Kit: the portrait in its ring, the tabs, the macro grid and the chosen icon in the Button Border, the command box, the icon picker), Edit Mode's windows (Edit Mode Kit: the HUD Edit Mode window, the settings of a selected element and the layout dialogs, purely in looks laid over them, so saving a layout and combat afterwards are untouched), the AddOn list (AddOn List Kit: the list on its dark panel with the quest log's hover, the check boxes, the search box, the character dropdown with its arrow, the buttons in pairs) and the game's Options window (Options Kit: the category list and every settings page, their check boxes, sliders, dropdowns, key-binding fields and buttons in the kit, other addons' pages left as they are).
- Six more windows in the kit, each with its own switch under UI Modifications, Windows: the quest dialogs and the gossip window (Quest Dialogs Kit: the NPC in the portrait ring and their name on the title plate, the quest log's parchment page with its painted edge, the text in dark ink, the rewards in the Button Border), merchants (Merchant Kit: the vendor in the ring, the goods on the dark panel, each on its own card, items you can't use on a dark red one, the repair and sell junk buttons, the Buyback tab, the page arrows and your money on the coin plate), the auction house (Auction House Kit: the Buy, Sell and Auctions tabs, every list on the dark panel with the quest log's hover, the search box, dropdowns, column headers and buttons in the kit, the item slot's rim in its quality colour), trainers (Trainer Kit, class and profession trainers alike: the trainer in the ring, the list on the dark panel, the chosen row in gold and the ones out of reach in dark red, the category headers, the rank bar and the Train button), the guild tabard vendor (Tabard Kit: the emblem choices on full-size labels, the kit's arrows, the preview on a dark backdrop) and the flight map (Flight Map Kit: the window's rail and title plate round the map, the map, its routes and flight points untouched).
- The rest of the game's windows in the kit, each with its own switch under UI Modifications, Windows: the mailbox (Mailbox: the inbox and a letter you read on the parchment page in dark ink, what you write in the dark ink too, the address and money blocks on the dark panel, both tabs on one stone), the bank (Bank: in your bags' Window Background, Item Border and Item Background, following them as you change them, its side tabs in the Side Tab Border), the guild bank (Guild bank: the guild's emblem in the ring, the slots as your bags', the bank tabs in the Side Tab Border, the logs and the info on the dark panel, the tab settings like the macro icon picker), trade (Trade: both players in their rings and their names on the title plate, the items on dark panels), the loot window and the group loot rolls (Loot windows: the roll timer in the Progress Bar Border), books, plaques and letters (Books and letters: every material on the kit's parchment page in dark ink), the guild charter and the guild registrar (Guild charter), the inspect window (Inspect: like your character window), the dressing room, the barber shop, gem socketing, the pet stable, the battleground scoreboard and its results (PvP windows), the battlefield map's frame (the map untouched), the ready check, split stack and colour picker (in the popup dialogs' look, following Parchment: Dialogs), the calendar and its event windows (the month and year on the title plate, the days as dark cards, today in gold), the clock and the stopwatch, the chat channels window and the help window. A window this client doesn't have is left alone.
- Check boxes and radio buttons: the game's checked, highlight and disabled art no longer shows through the kit's check box on buttons without a pressed look.
- No eye strain: every text-heavy area of the reskin -- lists, option sections, settings pages, rosters, chat, tooltips, the trackers, the damage meter, dialogs -- now lies on the palette's darkest tone inside its rail instead of on the plain brown stone, rows striped in a neutral dark. Where a frame has a Parchment option, the dark panel is there only while the parchment is off.
- Every window's title sits on its title plate in the title face your Font Style sets, and a window's round portrait ring always shows its icon: the Macros window's title and icon, the character window's own portrait (with Class Icons off) and the spell book's icon were off before.
- Dialogs: a button's label keeps its own colour on the parchment and sits over its red plate, readable; the world refresh notice's text is in the dark ink.
- Configurator and Dynamic UI Modification with more depth, easier on the eyes: every option section lies on a dark panel of the palette inside its iron rail, its rows striped in a neutral dark instead of brown. Dynamic UI Modification is wider, each column on its own dark panel with striped rows, the text at the interface's full size in the palette's text colour and the headings in its gold.
- Popup dialogs in the kit (Dialogs Kit, UI Modifications, Windows: Popup dialogs): the game's popups -- confirmations, the world refresh notice, Release spirit, a guild invitation (its own window with the guild's tabard too, where the game has one) -- on the kit's stone inside its single rail, their buttons on the red plates. A Parchment option for them (Dynamic UI Modification, Parchment: Dialogs) lays the paper with its painted edge on the stone, the message in dark ink set for the sheet.
- Chat: smooth scrolling. The mouse wheel, the scroll buttons and page up / down glide the chat windows and the whisper windows instead of jumping a line at a time; a fast spin runs on smoothly, a message that arrives while you read further up keeps the view still, and jumping to the bottom or the top is at once. Smooth Scrolling (Chat Tweaks) switches it off, and Reduce Motion keeps the old jumps.
- UI Scale: changing the game's UI Scale (or the resolution, or a size in Edit Mode) no longer leaves the reskin out of step. Once the game has settled, the backgrounds are laid again at their one density, the action bars' backdrops, tabs and joins follow the bars, windows saved near a screen edge are kept on the screen, the grid of Unlock the Windows is drawn for the new screen, the quest tracker and the square minimap are placed again, and the configurator shrinks to fit a screen it would run off. `/uiscaledump` shows the scale and what was laid again.
- Unlock the Windows: while you drag a window and scale it with the mouse wheel, a small plate over it shows its size against its normal size ("Size 115%") and how to get back. The wheel steps by 5 % of the normal size and stops at 100 % with a click, so a window is easy to bring back exactly. A window dropped at its normal size keeps no scale, and Reset positions returns each window to its own normal size.
- Tooltips can have a parchment sheet too (Dynamic UI Modification, Parchment: Tooltips): the paper with its painted edge on every reskinned tooltip, following its size, and the lines in dark ink by the parchment rule: titles and text dark, item quality, red and green lines and class colours as dark shades of their own. Money and the health bar keep their colours. The tooltip's inks are set for the sheet's darker paper, at 4.5 : 1 or better.
- Character window: its parchment ends in the same painted brush strokes as the quest log's, on every side. The Parchment sheet now lies on the pane's open paper instead of running under the divider and the rails, and the Parchment window background keeps the window's stone with a parchment layer inside the rails, its edges torn over the stone.
- Reputation and Skills tabs: the progress bars' borders are drawn 15 % smaller, in every Progress Bar Border look, the fill fitted into the smaller opening. Other windows' bars are unchanged.
- Equipment Manager: the equipment sets' icons, the set icon picker's icons and the slot flyout's buttons wear the Button Border like every other slot, the chosen set and icon with the gold rim, and they change with the Button Border.
- Voice Over overlay in the kit while the reskin is on: the rail and stone, the 3D portrait in the round portrait ring, a parchment sheet with the painted edge for the lines, the speaker's name on the red title plate and the kit's stop and skip glyphs, in all three Kit Colours looks. With the reskin off it is as before. Subtitle pages no longer fade in with Reduce Motion on.
- Quest List: a quest row's mouseover border is the Quest Log's own, fitted to each row whatever it held before (a header or a quest) and after the panel's width changes; a zone header lights up on mouseover again after the list refreshes, and only the row under the mouse lights when the reskin comes on.
- Route: the Tracking Notice, the Direction Arrow's texts, the World Marker's texts and the distance under the minimap follow the Fonts options (their face, size and outline, the Font Styles too), at once when they change. The names are in the interface text face, the distances in the chat and numbers face.
- Contacts window: its portrait icon is shown at the size every window's portrait has, inside the ring's opening.
- Dark Mode's Brightness slider is now Default UI Brightness, saying that it darkens the game's own art; the Font Style row says that it is a preset that changes every font at once.
- Chat on parchment has its own inks: each kind of chat is a dark shade of its own colour, designed to read on the paper and to stay apart from the others (say in dark brown, guild green, party blue, raid amber, raid warnings red-orange, whispers plum, Battle.net whispers teal, channels rosewood, yells red, system messages ochre, loot green). Your own chat colour choices are recognised. Lines the game protects from addons (often in instances and combat) take their ink too.
- Chat on parchment keeps its class-coloured names and its links: the channel tag, the player's name, a coloured sender and the links on a line's first row keep their bright colours, each on a small soft band of warm dark brown behind it (Shade Behind Names, Chat Tweaks), so they read without an outline; the rest of the line, NPC speech included, is dark ink with no band. The whisper windows follow the same rules on their own parchment.
- Names In Chat (Chat Tweaks): write players' names in full, as initial and surname (P. Skillybones), as name and initial (Professor S.), or as the first name or surname alone, in the chat and the whisper windows. The name is still a link to the player.
- The chat reads in your reading face: Chat text now follows the Interface text face unless you choose another (it used to fall back to the narrow Chat & numbers face, so under a Custom style the chat stayed in the numbers' font). Chat on parchment has its own font choice and size (Text tab, Chat on parchment): by default the chat's face in its semibold cut where it has one, heavier so the dark ink reads on the paper, and each Font Style sets it. The chat's lines keep the chosen font whatever resets them, and the whisper windows follow. Switch the parchment off and the chat's own font is back at once.
- Configurator reorganised: UI Modifications is now switches and sliders on eight tabs instead of fifteen: General (the reskin switch, Dynamic UI Modification, fading, reduced motion, names), Windows and HUD (which areas the reskin dresses, and what to hide), Combat, Unit Frames & Bars, Chat & Tooltips, Text and Dark Mode / Other. Each feature starts with its own switch and its options sit under it, dimmed while it is off; an option that needs another (Icon Size under Your Buffs, Use Guild Funds under Auto Repair, Backdrop Opacity under Dark Backdrop) sits indented under it and says which switch wakes it. The same goes for the Quest List, Route, Services, Custom Sounds and Voice Over pages.
- Dynamic UI Modification is the one place for the look of the reskin: the borders, Kit Colours, every background and backdrop, the minimap's shape and border, and now the parchment sheets, Hide Page Arrows and Merge With Services too. These are no longer rows on UI Modifications. It opens with any part of the reskin on (the action bars reskin is no longer needed), and UI Modifications' General tab has a button for it.
- Buffs & Debuffs and Error Messages moved into UI Modifications (the Combat tab) from pages of their own; each keeps whether it was on. Tweaks lost its own switch: its options (hide the micro menu or the bag bar, the minimap coordinates, chat notices, the world text scale) each switch one thing and sit on the HUD, Combat and Chat & Tooltips tabs.
- Fonts: the Text tab puts the Font Style and the four size sliders first; the single faces per role are under Advanced.
- Route: Marker Size is now Route Dot Size, on the Drawing tab beside the routes it sizes; the Notice tab is Arrival.
- Borders, one choice per kind for every window: Dynamic UI Modification has a Borders section with Button Border (the action bars, micro menu, bag bar, bags, equipment slots and spells), Side Tab Border (every window's side tabs and the spell book's category tabs), Progress Bar Border (every progress bar: reputation and skills, professions, legacy, guild, experience, the tracker, tooltips, the damage meter, the unit frames), Nameplate Border, Round Border (every round icon's rim: passive spells, the legacy, guild and group finder rings, the Services bar's round buttons: the gem ring or a thin ring in the buttons' looks) and Aura Border (your buffs and debuffs, the target's and the nameplates': the plain black edge or a thin rim, the debuff colour kept). Each changes every window at once; the border choices the notes below mention per window are these.
- Dynamic UI Modification opens one overview: every border and every bar's and window's backgrounds as dropdowns in one panel. Clicking a bar or window still opens its backgrounds with pictures.
- Action bars: the buttons wear a thin iron rim instead of the gem-cornered slot (the spell icon filling it to the rim's bevel), and one backdrop frames Action Bar 1 instead: the slot's rim drawn round the whole bar, with the four red gems on its corners only and stone behind the buttons. A bar snapped to Action Bar 1 in Edit Mode (or to one snapped to it) joins it: as wide a bar widens the backdrop, a narrower one such as the stance or pet bar gets a tab of the same frame tucked under it. The orbs at the bar's ends keep their red gems. Dynamic UI Modification has two new choices for the action bars: Button Border (Thin iron, Hairline, Rounded corners, Iron with gold line, or Sunk: a soft shadow inside the rim) and Bar Backdrop (Red gems, Iron gems or None), in any combination.
- Micro menu and bag bar: the same as the action bars. Thin rims on the buttons, one backdrop round each bar with its four gems, and their own Button Border, Backdrop, Backdrop Background and Button Background choices (in Dynamic UI Modification).
- Micro menu matched to the bag bar: its buttons are the size of the bag slots and spaced as they are, and both backdrops keep the same distance to the rims, so at the same Edit Mode size the two bars line up as one set. The game's spacing comes back with the reskin off.
- Backdrops that meet become one shape: where a narrower one sits on a wider one (the bag bar on the micro menu, a bar snapped to Action Bar 1) the narrower one's side rails run on into the wider one's rail through an L-shaped joint, its corner gems and the rail between them drop away, and the backgrounds meet. Backdrops side by side join too: a horizontal bar against an upright one (the micro menu against a vertical bag bar) becomes one L shape, and two bars of the same height side by side become one frame. The backdrops' top and bottom rails are heavier than their sides, as the rest of the kit's frames are, and every backdrop's rails are the same size.
- New Dynamic UI Modification button at the top of the configurator: it closes the configurator, darkens the world and lets you pick the action bars' look on the bars themselves. Hover the action bars, the micro menu or the bag bar and click one: a panel shows every Button Border, Bar Backdrop, Bar Background and Button Background (Stone, Cracked concrete, Iron plate, Parchment, Leather, Dark or None) as a picture, and each one goes onto the bars as you click it. Done or Escape finishes; clicks on the bars cast nothing meanwhile. Button Border now changes without a reload. The new Button Background choice sets what an empty button shows inside its rim.
- Bags: the item slots wear the same thin rims as the action bars instead of the gem-cornered slots; the item's quality colour stays round its icon. Dynamic UI Modification has, for the bags, Window Background (the page stone, or stone, cracked concrete, iron plate, parchment, leather or dark over the whole window), Item Border and Item Background (what an empty slot shows) choices, with pictures when you hover your bags (it opens them if none is open) and click. An empty bag slot, in the bag windows and on the bag bar, now shows the chosen background instead of the game's empty-slot picture.
- Backgrounds never stretch: every background in the interface (window stone, list boxes, the stone and parchment pages, the backdrops round the bars, empty slots) now repeats at one resolution on the screen. A bigger window, or one scaled up with the mouse wheel or in Edit Mode, shows more of its stone instead of a blown-up copy, and every window's stone is equally sharp. The stone and parchment pages are now seamless textures taken from the middle of their old pictures, so the carved window columns at the sides of the stone page are gone.
- Bags: Window Background's "Page stone" and "Cracked concrete" were now the same texture and are merged into Cracked concrete, the default.
- Professions book page: the profession spells wear the Button Border (each rim hugging its icon), the rank bars the Progress Bar Border, and a Book Page Background choice (Dynamic UI Modification, while the book page is open) sets what lies behind the profession cards.
- Crafting page: the reagent slots wear the Button Border (each rim hugging its icon), the rank bar the Progress Bar Border and the finished item the Round Border. Professions (Dynamic UI Modification, while the crafting page is open) has Crafting Page Background and Recipe List Background choices.
- Spell book: the spells wear the thin rims the buttons wear, each hugging its icon, and Spell Book (UI Modifications, under Spell book, and Dynamic UI Modification while the spell book is open) has a Spell Border choice: the gem slot or one of the five thin looks. Passive spells keep their round rim. The category tabs above the spells follow Side Tab Border: with a thin look each tab is a square rim with its icon filling it.
- Side tabs: every window's side tabs (collections, group finder, guild, legacy, quest log, professions) take the character window's size and look, and one Side Tab Border choice (Dynamic UI Modification) changes them all together: the character window's gem slot (the default) or one of the thin rims the buttons wear.
- Reputation and skill bars: a Progress Bar Border choice (Dynamic UI Modification, with previews) for the bars in the reputation and skills lists and their details, one choice for both: the ornate bracket with its diamond ends (as before), the cast bar's, or the thin rims the buttons wear made into bars (thin iron, hairline, rounded, iron with a gold line, sunk). It changes at once.
- Character window: the equipment slots wear the same thin rims as the action bars and bags instead of the gem-cornered slots, the item's icon filling the rim and its quality colour kept round it; an empty slot still shows what goes there. Dynamic UI Modification has, for the character window, Window Background (its own stone, or stone, cracked concrete, iron plate, parchment, leather or dark) and Item Border choices, and Dynamic UI Modification offers them too (it opens the window if it is closed).
- Character window: the panes no longer lay a second stone over the window's own, so the Skills, Reputation, Honor and Currency tabs and the space behind the character show one continuous stone.
- Square minimap: Minimap (Dynamic UI Modification) has a Shape choice, Round (the painted ring) or Square (the whole square map), and a Square Border for it: the windows' frame with its gem corners, a single iron rail, the action bars' heavy frame with red or iron gems, or none. Dynamic UI Modification offers both with previews. Other addons' minimap buttons are told the map is square.
- Square minimap merged with the Services bar (Minimap Kit, Merge With Services, on by default): with the square shape and the window frame or single rail border, one frame runs round the map and the service icons under it. A Services plate separates the two, the icons spread across the map's width on the frame's stone, and the zone name rides the frame's top rail on the red header the windows wear, with the tracking button and the calendar on its ends. Changing the Button Border in Dynamic UI Modification changes them at once.

- Text on parchment is dark ink across the interface: wherever the background behind text is parchment (the Parchment options for the objective tracker, the quest tracker, the chat and the whisper windows and the character window, Parchment chosen as the character window's or the professions recipe list's background, and the quest log and quest list pages), the text turns dark and loses its outline.
